# 日日好・勞安室團隊協作展示版

獨立的單頁靜態展示網站，無須安裝套件。

## 開啟
直接開啟 `index.html`，或上傳到全新的 GitHub repository，於 Settings → Pages 選 Deploy from a branch → main → /(root)。

## 注意
- 模擬角色切換並非登入或安全權限；不可存放真實公司敏感資料。
- 本機 localStorage 鍵值為 `rrh_team_demo_v1`，不同裝置不會同步。
- 不使用原版 V1 的 localStorage 鍵值，也不覆蓋 V1 GitHub repository。
- 若需要真正多人同步，下一階段需加入安全的後端驗證、資料庫與權限測試。
